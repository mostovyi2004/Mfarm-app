# Застосунок для малого фермера (робоча назва)

Відкритий офлайн-застосунок для особистого селянського, сімейного чи невеликого фермерського господарства: поля, тварини, корми, склади, переробка, гроші, документи, навігатор легалізації та вбудована база знань.

- Працює на Android-телефоні, планшеті, Windows і Linux — без інтернету.
- Дані господарства зберігаються лише на пристрої фермера й нікуди не надсилаються.
- Технології: Dart + Flutter, SQLite.
